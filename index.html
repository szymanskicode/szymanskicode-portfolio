goBIG Forms (Main Project)

React Next.js Node Express.js TypeScript Clerk MongoDB

Aplikacja typu SaaS do budowy formularzy, umożliwiającą tworzenie dynamicznych formularzy za pomocą interfejsu drag-and-drop oraz ich publiczne udostępnianie poprzez linki. System zawiera bezpieczne uwierzytelnianie (Clerk), panel użytkownika z analityką oraz obsługę zbierania danych w czasie rzeczywistym opartą o Prisma i PostgreSQL. Całość zaprojektowano z myślą o skalowalności, czystej architekturze i intuicyjnej obsłudze dla osób nietechnicznych. SaaS-style form builder application, featuring a drag-and-drop interface for creating dynamic, shareable forms. The platform includes secure authentication with Clerk, a user dashboard with analytics, and real-time data collection powered by Prisma and PostgreSQL. It’s designed with scalability, clean architecture, and an intuitive experience tailored for non-technical users.
